😉 关于 U校园 AI 答题助手

"license MIT"　"Tampermonkey 支持"　"Groq API"

U校园 AI 答题助手是一款基于 Tampermonkey 的浏览器辅助脚本，通过调用 Groq AI 接口识别 U校园当前题目、分析题目内容并生成参考答案。

支持自动填写答案、连续答题以及程序暂停与恢复等功能，帮助用户更加方便地完成课程练习。

---

😮 主要功能

☑️ AI 智能答题：自动提取当前页面题目，调用 Groq AI 分析并生成答案。

☑️ 自动填写答案：将 AI 生成的答案自动填入对应题目。

☑️ 连续答题：支持自动提交当前答案，并尝试进入下一题继续答题。

☑️ 手动辅助模式：可以只获取答案，不开启自动填写。

☑️ 一键暂停程序：答题过程中可以暂停后续自动操作。

☑️ 继续运行：暂停后可以恢复后续答题流程。

☑️ API Key 保存：支持保存 Groq API Key，避免重复输入。

☑️ 模型选择：支持选择脚本配置中提供的 Groq 模型。

☑️ 答案复制：可以复制 AI 生成的答案。

🤔 安装教程

1. 安装插件（若已安装可略过此步骤）

要使用脚本，首先需要浏览器安装 Tampermonkey（篡改猴）脚本管理器。

安装完成后，确保插件已经启用，并允许其在 U校园页面运行。

2. 安装答题脚本

1. 打开 Tampermonkey 管理面板。
2. 点击添加新脚本。
3. 删除编辑器中的默认代码。
4. 将完整的 U校园 AI 答题助手代码复制进去。
5. 按下 Ctrl + S 保存。
6. 返回 U校园页面并刷新。

刷新后，如果脚本正常运行，页面中就会出现答题助手面板。

3. 配置 Groq API Key

首次使用需要配置 Groq API Key。

1. 获取自己的 Groq API Key。
2. 打开 U校园答题助手面板。
3. 找到 API Key 输入框。
4. 粘贴自己的 API Key。
5. 点击保存按钮。

注意：API Key 属于个人接口凭证，请勿随意泄露。

😎 使用教程

1. 手动辅助答题

如果只想让 AI 帮忙分析题目，可以使用手动模式。

操作步骤：

1. 进入 U校园练习页面。
2. 确认 API Key 已经配置。
3. 关闭自动填入选项。
4. 点击「获取当前题目答案」。
5. 等待 AI 生成答案。
6. 在答案显示区域查看结果。
7. 可以点击复制按钮复制答案。

此模式下，脚本只负责获取题目和生成答案，不会自动提交。

2. 自动连续答题

如果希望脚本自动填写并连续处理题目，可以开启自动填入。

操作步骤：

1. 进入 U校园练习页面。
2. 确认 API Key 和模型配置正确。
3. 勾选「自动填入」。
4. 点击「获取当前题目答案」。
5. 等待脚本识别题目并生成答案。

自动答题流程：

获取题目 → AI 分析 → 生成答案 → 自动填入 → 点击提交 → 点击继续 → 获取下一题。

脚本会按照上述流程尝试连续答题。

---

🥳 暂停与继续功能

1. 暂停程序

当脚本正在自动答题时，如果需要暂时停止，可以点击「暂停程序」。

暂停后：

☑️ 暂停后续自动答题步骤。

☑️ 不再主动执行后续提交和下一题操作。

☑️ 当前已经发出的 AI 请求不会被强制取消。

☑️ 当前操作结束后，会在后续流程节点等待。

2. 继续程序

点击「继续程序」，即可恢复后续答题流程。

特别说明：暂停功能不是取消任务。如果点击暂停时 AI 正在生成答案，当前请求仍可能继续执行，完成后才会进入暂停等待状态。

😵 常见问题

1. 点击获取答案没有反应

可能原因：

- API Key 填写错误。
- Groq API 服务暂时不可用。
- 网络连接异常。
- 当前页面没有成功识别到题目。

建议检查 API Key 和网络连接，并确认当前页面已经加载完成。

2. AI 能生成答案，但无法自动填入

可能原因：

- U校园页面结构发生变化。
- 当前题目控件没有被正确识别。
- 页面使用了特殊 iframe 或动态加载组件。
- AI 生成的答案格式不符合题目要求。

建议先关闭自动填入，测试 AI 是否能够正常生成答案。

3. 能够填写答案，但不能自动提交

可能原因：

- 提交按钮无法正确识别。
- 页面尚未加载完成。
- 页面存在多个相似按钮。
- U校园页面交互逻辑发生变化。

4. 自动答题中途停止

可能原因：

- 当前题目无法识别。
- AI 请求失败或超时。
- 答案填写失败。
- 提交按钮或下一题按钮无法识别。

可以查看脚本状态提示，确认当前页面是否正常。

5. 暂停后无法继续

可以尝试点击「继续程序」。

如果期间刷新了页面或切换了练习，原来的答题流程可能无法恢复，需要重新启动脚本。

⚠️ 使用注意事项

1. 使用前请确保 Groq API Key 有效。
2. 请确保 Tampermonkey 已启用。
3. 自动答题时，尽量不要手动切换题目或刷新页面。
4. 首次使用建议先测试一道题，确认填写和提交流程正常。
5. AI 生成的答案可能存在错误，建议自行检查。
6. 暂停功能不会强制取消已经发出的网络请求。
7. Groq API 的模型、额度和服务状态可能发生变化。

---

❤️ 推荐使用方式

第一次使用：

配置 API Key → 测试 AI 获取答案 → 检查答案 → 测试自动填入。

日常使用：

打开 U校园 → 开启自动填入 → 点击获取当前题目答案 → 等待脚本连续答题。

需要暂停时：

点击「暂停程序」；需要恢复时，点击「继续程序」。
